# TikTok 欧盟定价速算

说一句「这个品在德国卖多少钱」，直接给出**含 VAT 的应定价**和六项费用拆解
（佣金 / VAT / 支付手续费 / 智能推广 / €3 关税 / 直邮运费）。

- 覆盖欧盟全境 27 国（VAT 27 国齐全，类目佣金 13%/15%）
- 德/法/意/西/爱五国为实测直邮价卡，其余按德国价卡代理估算并标注
- 每天每 IP 免费 15 次，无需注册
- 支持按件数折算包裹重量、体积重（cm³÷8000）、超重超长直接拒算

## 用法

```bash
python scripts/quote.py --country 德国 --cost 40 --weight 600 --category "Home Supplies" --margin 0.25
```

## 说明

- 计算公式与费率库不随包分发，全部在服务端；客户端只负责收集参数、调用接口、呈现结果
- 接口有请求签名，必须使用 `scripts/quote.py`，自己拼 HTTP 请求只能拿到粗略价
