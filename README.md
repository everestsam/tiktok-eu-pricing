# TikTok 欧盟定价速算（免费版）

一句话问价 → 直接出价 + 费用拆解。

## 装法

复制整个目录到 WorkBuddy 技能库（或按 SkillHub 说明安装），确认 `scripts/quote.py` 可执行。

## 用法

```bash
python scripts/quote.py --country 德国 --cost 40 --weight 600 --category "Home Supplies" --margin 0.25
```

| 参数 | 说明 |
|---|---|
| `--country` | 目的国：**欧盟全境 27 国**（德/法/意/西/爱有实测直邮价卡；荷/比/波/瑞/丹/芬/奥/葡/捷/匈等按德国价卡代理估算并标注） |
| `--cost` | 成本价（人民币） |
| `--weight` | 重量（克） |
| `--category` | 类目（Home Supplies / Kitchenware / Womenswear / Household Appliances…），决定佣金 13% 或 15% |
| `--margin` | 目标利润率（占售价），默认 0.25 |
| `--price` | 给定售价，进入验算模式 |
| `--promo` | Smart Promotion 费率（默认 2%，大促最高 6%，Campaign Plus 最高 8%） |
| `--new-seller` | 新卖家优惠费率（EU5 4%/60 天，新拓展市场 2%/90 天） |
| `--cargo` | 货物类型：普货（默认）/特货/敏货，价卡不同 |
| `--shipping` | 1=包邮（默认，按直邮价卡计运费）0=买家付运费 |
| `--dims` | 包装尺寸 长x宽x高（cm），按体积重计（cm³÷8000） |
| `--qty` | 件数（配合 --unit-net 折算包裹重量） |
| `--unit-net` | 单件净重(g)；给了就按 件数×净重+包装 折算 |
| `--pack` | 包装重量(g)，固定值 |
| `--pack-rule` | 分段包装规则，如 `1-2:10,3-5:20,6+:30` |

## 本机凭据

首次运行时会向 `api.geovantage.net` 登记一个随机 `install_id`，换回一把**仅属于本机**的签名密钥，
保存在 `~/.tiktok-eu-pricing.json`（可用环境变量 `EU_PRICING_CONF` 改路径）。
包里**不含任何密钥**；只登记随机 ID，不上传任何业务数据、成本或客户信息。

## 免费额度

每天每 IP **50 次**算价，额度用完次日 0 点重置。

## 隐私说明

- 只处理你**主动提供**的成本、重量、类目、售价等信息；不索取任何买家资料
- 输入里若含手机号、邮箱、身份证等特征会被自动打码

## 能力边界

- ✅ 欧盟全境单国单 SKU 定价、验算、费用拆解
- ❌ 多国批量对比、Excel 批量回填、退货率/偏远地区/超尺寸全成本模型 → 完整版

## 数据来源

费率来自公开渠道整理（欧盟佣金表、27 国 VAT、**跨境直邮 per Parcel+per Kg 价卡（德/法/意/西/爱五站）**、退货费率、2026-07-01 起的 €3 低值关税）。
直邮计费：50g 起重、按克计费、单包最大 30kg、体积重 = 体积 cm³ ÷ 8000 取高者。
计算在服务端完成，本包不含费率与公式；实际扣费以卖家后台结算单为准。
